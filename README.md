# 🛒 Ecommerce Website

A full-stack Ecommerce web application built using **Spring Boot**, **Spring Data JPA**, **Hibernate**, **React**, and **H2 Database**. It provides REST APIs for product management, image upload, search, and CRUD operations with a responsive React frontend.

## 🛠️ Tech Stack

- **Backend:** Java, Spring Boot, Spring Data JPA, Hibernate
- **Frontend:** React, Axios, Bootstrap
- **Database:** H2 Database
- **Build Tool:** Maven
